# base-environment-codex

用于 Codex 云环境的基础项目仓库。

## 开发环境

当前使用云环境预装的 Git、Python 3 和 Node.js，无需额外安装依赖。
仓库尚未选择应用框架，也没有需要启动的服务。

## 开始开发

1. 在 Codex 云环境中打开此仓库。
2. 根据项目需求添加源代码、依赖声明和测试。
3. 添加依赖或服务后，同步更新本文件中的安装、启动和测试说明。

每个云任务已有独立环境，直接使用现有仓库检出即可，无需额外创建 Git worktree。

## 验证

当前仓库仅包含初始化文件，暂无应用测试。可检查工作区状态：

```sh
git status --short
```
